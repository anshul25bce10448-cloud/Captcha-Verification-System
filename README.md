# Captcha-Verification-System


## Group No. 101

An improved CAPTCHA verification system designed to distinguish
between genuine human users and automated bots.

## Features

- Dynamic CAPTCHA generation
- Randomized CAPTCHA characters
- CAPTCHA expiration
- Hidden honeypot verification
- Response-time analysis
- Mouse interaction analysis
- Multiple-attempt detection
- Risk scoring
- Human/Bot classification
- Machine-learning prototype

## Technologies

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### Machine Learning

- Python
- Pandas
- Scikit-learn
- Random Forest

## Project Workflow

User Request
↓
CAPTCHA Generation
↓
Visible CAPTCHA + Hidden Honeypot
↓
User Interaction
↓
Behaviour Analysis
↓
Risk Scoring
↓
Human / Bot Classification
↓
Access Granted / Denied

## Running the Project

Install dependencies:

npm install

Start the server:

npm start

Open:

http://localhost:3000

## Running the ML Model

Open the ml folder:

cd ml

Install dependencies:

pip install pandas scikit-learn

Run:

python model.py
